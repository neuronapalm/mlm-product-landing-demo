# PUREWELL DAILY BALANCE — демонстрационный лендинг

Адаптивный статический сайт по предоставленным макетам `desktop.png`, `mobil.png` и HTML-прототипу. Для публикации на GitHub Pages достаточно файлов в корне проекта.

## Сборка и запуск

Сайт не требует сборки. Для локальной проверки запустите статический сервер в этой папке, например `python -m http.server 8000`, и откройте `http://localhost:8000/`.

GSAP и ScrollTrigger поставляются локально в `assets/vendor/`. Поведение страницы остаётся доступным без анимации.

## Источники и границы фактов

- Композиция: утверждённые PNG-макеты и `purewell-prototypes-html/index.html`, переданные пользователем.
- Фотографии, упаковка и иконки: оптимизированные производные от каталога `графика`; исходники не изменялись.
- Изображение упаковки является рекламным концептом, не подтверждением состава или свойств продукта.
- Из исходных карточек изображений исключены встроенные неподтверждённые утверждения. Портреты обрезаны до иллюстраций без вымышленных имён и цитат.
- Информация о составе, эффективности, медицинских свойствах, условиях партнёрства и результатах не предоставлена и не заявляется как факт.
- Контакты: телефон, email и Telegram, указанные пользователем.

Перед использованием в качестве сайта реального продукта нужны подтверждённые сведения о нём и разрешение на публичное использование визуальных материалов. Сейчас сайт явно обозначен как демонстрационный.
